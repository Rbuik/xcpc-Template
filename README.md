# 💻 ACM / OI 算法模板库

一个专为个人复习与比赛准备的个人算法模板知识库。

## 📖 项目简介
本项目将个人的算法学习笔记和代码模板整理成了一个轻量级的静态网页。无需配置任何后端环境，使用纯前端（HTML + CSS + JavaScript）开发，通过读取本地 JSON 数据动态渲染页面。

## ✨ 核心特性
- **📂 完整分类**：严格对照个人笔记，包含 26 个核心分类（基础、数据结构、图论、DP 等）。
- **🔍 全局搜索**：支持按分类、标题、描述和代码内容进行实时全局搜索。
- **📱 响应式设计**：支持电脑端与手机端。电脑端左右独立滚动互不干扰，手机端自动折叠为上下布局。
- **🎨 代码高亮**：深色主题代码块，并强制自动换行，防止长行代码撑破页面。
- **🚀 极速加载**：纯静态页面，搭配 GitHub Pages，随时随地在任何设备上打开。
