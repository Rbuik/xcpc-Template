# 💻 ACM / OI 算法模板库

一个专为个人复习与比赛准备的算法模板知识库，支持全局搜索、代码高亮、主题换色、字体缩放和响应式排版。

## 📖 项目简介

本项目将个人的算法学习笔记和代码模板整理成了一个轻量级的静态网页。无需配置任何后端环境，使用纯前端（HTML + CSS + JavaScript）开发，通过读取本地 JSON 数据动态渲染页面，随时随地都能极速查阅算法模板。

## ✨ 核心特性

- **📂 完整分类**：严格对照个人笔记，包含26个核心分类，并带有欢迎首页。
- **🔍 全局搜索**：支持按分类、标题、描述和代码内容进行实时全局搜索。
- **🎨 主题换色**：内置7款主题配色，支持一键切换并自动保存。
- **✨ 代码高亮**：深色主题代码块，自动识别以`<`开头的二级标题，并随主题颜色自动变色放大。
- **📱 响应式设计**：手机端自动折叠为上下布局，目录折叠在顶部，防止小屏幕下排版错乱。
- **📏 代码自适应**：强制长行代码自动换行，防止撑破页面，同时支持横向滑动。
- **🔠 字体大小调节**：右下角支持一键放大/缩小全站字体（50%-250%），并自动保存阅读习惯。
- **🖥️ 独立滚动布局**：电脑端左侧目录与右侧代码独立滚动，互不干扰，阅读体验极佳。

## 📁 目录结构

```text
├── css/
│   └── style.css          # 页面样式表（含主题变量、独立滚动、手机自适应、字体缩放、深色代码主题）
├── js/
│   └── main.js            # 核心逻辑（数据加载、分类渲染、全局搜索、字体缩放记忆、主题切换记忆、代码高亮）
├── data/
│   └── all.json           # 所有算法模板的数据源（含26个分类）
├── README.md              # 项目说明文档
└── index.html             # 网页主入口
```

- 在线访问：已部署至 GitHub Pages，可直接访问 https://Rbuik.github.io/xcpc-Template/

## 🛠️ 如何添加新算法

所有的算法数据都存储在 data/all.json 中。你只需按照以下 JSON 格式追加即可：
```text
json
{
    "category": "基础模板",
    "title": "新的算法名称",
    "description": "算法的简单说明",
    "code": [
        "< 新的二级标题",
        "// 在这里写你的 C++ 代码",
        "#include<bits/stdc++.h>..."
    ]
}
```
⚠️注意：
- 推荐使用数组形式 [] 来写代码，这样在源码里阅读更美观。
- 标题前面加 <，网页上就会自动变色并放大，且隐藏 < 符号。
- 最后一条记录后面不能有逗号。
